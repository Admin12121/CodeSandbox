## Project Summary

This project is an automated cybersecurity workspace platform for individuals, teams, and organizations. It combines a cyber range, malware sandbox, reverse-engineering workspace, digital forensics platform, SOC investigation UI, and collaborative case-management system into one browser-based product.

Users can create a personal workspace, upload suspicious files, run automated analysis, launch isolated labs, investigate evidence, take canvas-style notes, and collaborate with others in real time. The platform automatically detects uploaded file types such as executables, APKs, memory dumps, disk images, PCAPs, logs, archives, scripts, and documents, then routes them to the correct analysis pipeline. For example, binaries can trigger reverse-engineering analysis, memory dumps can trigger Volatility jobs, PCAPs can trigger network analysis, and suspicious files can trigger YARA/Sigma/IOC extraction.

The system supports three usage levels: trial, personal workspace, and organization workspace. Trial users get limited weekly resources such as sandbox time, CPU, RAM, GPU, storage, reset count, and AI/analysis computation. Personal users get their own Notion-like cybersecurity workspace where they can create labs, cases, notes, and invite friends for limited collaboration. Organizations get stronger limits, team management, shared labs, case collaboration, realtime chat, synchronized simulations, and advanced admin controls, but with higher pricing.

Billing supports multiple payment providers such as eSewa, Khalti, Stripe, and manual/admin-approved payments. Plans control access to labs, sandbox runtime, AI analysis, storage, team size, GPU/CPU usage, weekly reset limits, and organization features.

The platform uses a multi-database design. The master database stores global users, sessions, platform roles, platform permissions, personal workspaces, organization registry, subscriptions, invoices, payment records, coupons, audit logs, and organization database mappings. Each organization receives its own separate database for organization-local data such as cases, case notes, artifacts, labs, collaboration records, realtime simulation state, organization roles, and organization permissions. Organization databases reference users through global `master_user_id` values instead of duplicating user identity.

RBAC is split into two levels. Application-level RBAC controls the platform itself, including user management, organization management, finance, billing, application settings, policies, terms and conditions, support tickets, technical operations, and platform SOC/security monitoring. Organization-level RBAC is separate and controls what members can do inside an organization, such as accessing labs, creating cases, joining investigations, managing evidence, collaborating in realtime, using sandboxes, running analysis, inviting members, and generating reports.

The investigation UI should feel like a cybersecurity version of Notion plus Eraser.io plus CodeSandbox. A user can open a lab or sandbox on one side, keep draggable notes or diagrams on the other side, attach evidence, generate timelines, chat with teammates, and convert findings into a final report.

Overall, the product is an automated cyber workspace where individuals and organizations can safely analyze files, run labs, investigate incidents, collaborate in cases, replay attacks, and manage security workflows from one platform.
